# 桌面 DP 与 Metal 适配摘要

1. 依据 VBT/AUX 和 EDID 选择外接接口及模式。补充 display-v14 F/G/H 映射后，目标 DP 可读取完整 EDID，并通过 4K60 模式检查。
2. 配套 core、Display、Accel、AGDC、XeMTL、Mesa ANV 与运行库，核对核心和 plugin 的独立源码基点。
3. 跟踪缓冲区实际内存类型，修正 RGBA16Float 纹理别名，验证池化和独立分配的 GPU clear 与 CPU 可见性。
4. 向 AGDC 发布当前原生模式的 NVRMTiming，同时核对 4K60 物理输出与 2× HiDPI 逻辑尺寸。

补丁位于 patches，关键源码位于 source。源码基点、组件关系和验证范围见根目录 docs/GRAPHICS.md。
