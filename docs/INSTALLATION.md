# 目标环境与移植准备

## 适用范围

已测试环境为 Core Ultra 7 265K、Z890M AORUS ELITE WIFI7、主板单 DP 输出、macOS Tahoe 26.7.2 / `25G332`。其他硬件、显示接口或系统构建需要独立适配。

公开材料包含源码、补丁和组件配置参考。移植时应准备本机 ACPI、CPU 配置、USB 映射与 SMBIOS，图形组件还依赖系统内配套用户态库及辅助程序。

## 环境准备

1. 在本地核对目标平台、设备 ID、固件信息、VBT 和显示器 EDID。
2. 备份重要数据与现有 EFI，确认目标系统卷和 ESP。
3. 从 Apple 获取完整安装器，按 [官方说明](https://support.apple.com/zh-cn/101578) 制作介质，并核对待抹除的目标宗卷。
4. 基于固定版本 OpenCore 的 Sample 与 Configuration 文档准备 EFI，自行生成 SMBIOS 身份并使用对应版本 `ocvalidate` 检查。

使用 InstallAssistant.pkg 时，需先取得完整安装器 App。安装器存放位置与系统安装目标应分别确认。

## 平台配置

CPU、ACPI 和固件参数以目标环境为准。自定义 ACPI 表应与当前固件表对照，避免沿用其他机器的地址、路径或端口假设。

已测试环境使用过 USBToolBox + UTBDefault，完整定制映射尚未验证。移植时应根据本机控制器和端口制作映射，并检查输入设备与蓝牙所属 USB 路径。

## 组件部署要求

| 部分 | 要求 |
| --- | --- |
| 图形核心 | 按固定基点准备 XeGfx、Display、Accel 与 AGDC，检查目标 x86_64 架构及 KPI 导入 |
| 用户态图形 | 配套 XeMTL、Mesa ANV、libdrm、translator 与 AIR/LLVM，核对动态链接依赖 |
| 内核缓存 | 在匹配系统构建的目标环境生成，核对实际包含与加载的组件 |
| Wi-Fi | 应用 d1 → d3 补丁链，固件与生成文件按上游构建要求准备 |
| 蓝牙 | 使用已验证组件组合，保持目标系统构建、设备 ID 与模式匹配限制 |
| 温度 | 官方 SMCProcessor 1.3.7，按 VirtualSMC 依赖顺序配置 |

各组件构建前置条件与补丁应用目录见 [构建说明](BUILD.md)。归档中的参考脚本含示例机器参数，使用前须核对目标路径、配置条件与配套文件。

## 功能检查

先检查实际加载模块、原生 DP 模式与 Metal 探针，再检查桌面合成及 HiDPI。显示验收需要同时满足物理 3840×2160、60 Hz、逻辑 1920×1080 与 HiDPI=true，并使用当前会话的实时结果。

无线和温度分别进行扫描、联网、配对、音频连接及 SMC 读取检查。每项记录系统构建、组件版本、测试方法和实际结果，覆盖范围见 [验证记录](VALIDATION.md)。
