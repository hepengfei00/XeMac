# 已知问题与验证缺口

下表保留尚未关闭的问题。现象、已有证据与待验证原因分别列出，避免将调查线索写成已确认结论。

## 系统设置图标延迟的参考线索

同源 WTLNvidiaGfx 项目的 [问题 #10](https://github.com/watchthelight-labs/WTLNvidiaGfx/issues/10) 描述首次加载图标时的占位与延迟，[问题 #6](https://github.com/watchthelight-labs/WTLNvidiaGfx/issues/6) 涉及 AIR digest 重复计算引发的 CPU 开销。它们可用于确定采样方向，Intel 路径的本机原因仍需独立验证。

调整 plugin 前需检查当前固定基点、已移植改动和配套运行库；对照首次与再次打开的采样结果，再判断相应修复是否适用。

## 版本相关限制

`RebaseRegions` 依赖原固件区域与自定义表的对应关系。BlueToolFixup 本地兼容补丁限定系统构建与设备 ID。图形驱动、用户态库与 AuxKC 也需要配套。

跨 BIOS、系统构建或设备迁移时，应先重新核对这些条件。基础联网、音频连接和温度可读分别代表对应阶段的结果，长期稳定与睡眠恢复需继续验证。
